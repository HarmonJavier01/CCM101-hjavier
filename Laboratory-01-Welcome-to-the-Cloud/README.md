# Laboratory 01 - Welcome to the Cloud

## Mission Overview
This laboratory introduces the basics of working in a cloud-based Linux environment using KillerCoda, covering user management, system exploration, and file organization.

## Objectives
- Access and use a cloud-based Linux environment
- Create and manage a new user account
- Investigate core system information
- Organize files and directories
- Build a GitHub-based portfolio to document the work

## Activities Performed
- Launched an Ubuntu 24.04 playground on KillerCoda
- Created a new user (hjavier) with sudo privileges
- Gathered system information (distro, kernel, CPU, memory, disk)
- Created a folder structure (Documents, Notes, Reports, Screenshots)
- Documented findings in Markdown files
- Built and pushed a GitHub repository

## Linux Commands Used
adduser, usermod, su, whoami, pwd, hostname, lsb_release, uname, lscpu, free, df, mkdir, nano, cat, git

## Skills Learned
- Navigating and managing a Linux environment via CLI
- Creating and administering user accounts
- Gathering and documenting system information
- Organizing a project using Markdown and Git/GitHub
