# Laboratory Activity 3: Become a Multi-Cloud Explorer

## Overview
This laboratory contains an investigation and comparison of the three major public cloud providers: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

## Directory Structure
* `aws-research.md` - Technical overview and core services of AWS
* `azure-research.md` - Technical overview and core services of Azure
* `gcp-research.md` - Technical overview and core services of GCP
* `cloud-platform-comparison.md` - Comparative tables and analysis
* `client-recommendations.md` - Solutions architect recommendations and decision matrix
* `reflection.md` - Learning takeaways and insights
* `screenshots/` - Terminal outputs and platform homepages

## Checkpoint 7: Linux System Investigation
* **Operating System**: Ubuntu 22.04 LTS
* **CPU Information**: x86_64 Architecture, 2 Virtual CPUs
* **Memory**: 4.0 GiB RAM
* **Disk Space**: 40 GB Root Filesystem

### Cloud Migration Mapping
If this Linux server were migrated to the public cloud, it could be hosted on:
* **AWS**: Amazon EC2 (t3.medium or t4g.medium instance)
* **Azure**: Azure Virtual Machines (Standard_B2s or Standard_D2s_v5)
* **GCP**: Compute Engine (e2-medium or e2-standard-2 instance)
